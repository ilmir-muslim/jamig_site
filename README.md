# Мечеть «Джамиг» — духовно-просветительский портал

Веб-платформа для публикации и управления исламским просветительским контентом: текстовые статьи, видео, аудио, а также структурированные курсы с уроками. Включает публичную часть для посетителей и закрытую студию для авторов и сотрудников.

## Стек технологий

- **Backend:** Python 3.13, Django 5.2
- **База данных:** SQLite (разработка), возможна миграция на PostgreSQL
- **Фронтенд:** Bootstrap 5, Font Awesome, Google Fonts (Inter, Amiri)
- **Дополнительные библиотеки:** WeasyPrint (генерация PDF), EbookLib (работа с EPUB), pandas/openpyxl (экспорт), pytils (транслитерация)

## Модели данных

### Пользователи (`accounts`)

- **User** — кастомная модель на основе `AbstractUser`. Аутентификация по email (без username). Три типа: обычный пользователь, сотрудник, автор.
- **Employee** — профиль сотрудника (должность, место работы, контакты, график).
- **SiteUser** — профиль обычного пользователя (дата рождения, город, интересы, настройки уведомлений).
- **Authors** — профиль автора (специализация, квалификация, соцсети, статистика публикаций).

### Контент (`materials`)

- **Category** — категории контента с сортировкой.
- **VideoContent** — видео с поддержкой встраивания (Rutube, YouTube и др.), длительность, обложка, прямой эфир.
- **AudioContent** — аудиофайлы (MP3, WAV, OGG), длительность, обложка, счётчик прослушиваний.
- **TextContent** — текстовые статьи с подзаголовком, обложкой, автоматическим расчётом времени чтения.
- **ReadingProgress** — прогресс чтения текстовых материалов для авторизованных пользователей.

### Курсы (`courses`)

- **Course** — курс с описанием, автором, статусом (черновик/опубликован/в архиве).
- **Lesson** — урок внутри курса с привязкой к видео-, аудио- и текстовым материалам.

### Публикации (`main`)

- **Post** — новости, статьи и уроки для главной страницы.

## Функциональность

### Публичная часть

- Главная страница с лентой новостей и публикаций
- Каталог материалов с фильтрацией по категориям
- Встроенный ридер для текстовых материалов с постраничной навигацией
- Плееры для видео и аудио
- Список курсов с детальным просмотром и структурой уроков
- Страницы авторов

### Студия (закрытая часть)

- Дашборд с общей статистикой
- CRUD для всех типов контента (тексты, видео, аудио)
- Управление курсами и уроками
- Привязка материалов к урокам через модальные окна

## Установка и запуск

Управление зависимостями и окружением осуществляется через [uv](https://docs.astral.sh/uv/). Проект использует Python 3.13 (зафиксирован в `.python-version`).

```bash
# Клонирование репозитория
git clone <repo-url>
cd jamig_site

# Установка uv (https://docs.astral.sh/uv/getting-started/installation/)
curl -LsSf https://astral.sh/uv/install.sh | sh

# Создание виртуального окружения (.venv) на Python 3.13
# и установка всех зависимостей из pyproject.toml
uv sync

# Активация окружения (опционально; uv подхватывает .venv автоматически)
source .venv/bin/activate  # Linux/Mac
# или
.venv\Scripts\activate     # Windows

# Миграции базы данных
uv run python manage.py migrate

# Создание суперпользователя
uv run python manage.py createsuperuser

# Запуск сервера разработки
uv run python manage.py runserver
```

### Часто используемые команды uv

```bash
uv sync                      # синхронизация окружения с pyproject.toml
uv add <package>             # добавить зависимость
uv remove <package>          # удалить зависимость
uv lock --upgrade            # обновить uv.lock
uv run <command>             # выполнить команду в окружении
```
